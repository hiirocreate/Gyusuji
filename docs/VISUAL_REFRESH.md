# 牛すじハンター風のビジュアル調整

「たんしおレモン」の『牛すじハンター』を参考に、BEEF HUNTER の表示だけを調整する。既存の Phaser + Vite / Colyseus 構成を継続し、新規ゲームや別エンジンへの移行は行わない。

## デザイン

2000年代のブラウザーすごろくRPGの、明るい草地、鮮やかな青い水面、小さなプリレンダ風キャラ、淡いクリーム色のマスを軸にする。細い白枠の四角い紺ウィンドウと白い文字を維持し、装飾を控える。タイトルの過剰な金属ロゴときらめきを抑え、キャラ選択には同梱キャラの立ち姿を添える。手番は既存の紺色強調で示す。

ゲームの名前、5キャラの能力、CPU設定、ネット対戦、ハウスルール、アイテム、移動経路、戦闘進行、イベント、演出待機時間、セーブ形式、通信、画面遷移は変えない。横640×324 / 縦360×684、フィールド280×280、ステータス180×140×4、チャット44pxの座標体系も変えない。

## 実装構成

- `packages/client/src/scenes/classicTerrain.ts`: 表示用タイルテクスチャと地形の見た目の共通化。
- `Boot.ts` / `Field.ts` / `titlebg.ts`: 派生テクスチャの準備と利用。マップデータや判定には手を加えない。
- `Status.ts` / `Battle.ts`: 既存の配置に従って情報の見やすさと背景の統一を調整。
- `Menu.ts` / `style.css`: タイトル、キャラ選択、紺色ウィンドウの視覚的一貫性。
- `packages/shared` / `packages/server` / `assets/data`: 今回の変更対象外。
