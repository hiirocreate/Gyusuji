# 牛すじハンター風のビジュアル調整

「たんしおレモン」の『牛すじハンター』を参考に、BEEF HUNTER の表示だけを調整する。既存の Phaser + Vite / Colyseus 構成を継続し、新規ゲームや別エンジンへの移行は行わない。

## デザイン

2000年代のブラウザーすごろくRPGを土台に、明るい草地・鮮やかな水面・淡いクリーム色のマスを生かす。タイトルは牛すじの紋章と読みやすい和題を組み合わせ、UIには金縁・クリーム色・琥珀・珊瑚・青緑を加え、ポップな冒険RPGらしいボタンとパネルにする。キャラ能力・マップ座標・移動・戦闘・イベント・対戦処理などのゲームルールは変えない。

ゲームの名前、5キャラの能力、CPU設定、ネット対戦、ハウスルール、アイテム、移動経路、戦闘進行、イベント、演出待機時間、セーブ形式、通信、画面遷移は変えない。横640×324 / 縦360×684、フィールド280×280、ステータス180×140×4、チャット44pxの座標体系も変えない。

## 実装構成

- `packages/client/src/scenes/classicTerrain.ts`: 表示用タイルテクスチャと地形の見た目の共通化。
- `Boot.ts` / `Field.ts` / `titlebg.ts`: 派生テクスチャの準備と利用。マップデータや判定には手を加えない。
- `Status.ts` / `Battle.ts`: 既存の配置に従って情報の見やすさと背景の統一を調整。
- `Menu.ts` / `style.css`: タイトル、キャラ選択、紺色ウィンドウの視覚的一貫性。
- `gen/polish_assets.py`: 25種のアイテム・ダイス・宝箱・がびょう・金袋などの高解像度オリジナル素材を出力。既存のID/フレーム対応を維持。
- `Field.ts` / `Overlay.ts` / `chat.ts`: 2回目のアイテムタップで使用、足あと・使用エフェクト、PC横・スマホ縦の初期向きと縦横切替・終了ボタン、短いダイスアニメーション。
- `Menu.ts`: WebとAndroidで共有するネット対戦ロビーから、ホストが標準・短編・長編マップを明示的に選び、参加者全員が選択中マップを確認できるようにする。
- `Status.ts`: HP・MP・G・歩数を読みやすく明示。
- `packages/client/e2e/visual.spec.ts` / `orientation.spec.ts` / `network-map.spec.ts`: PC横・スマホ縦の既定、向き切替、ネット対戦マップ同期、終了・2段階アイテム選択の実画面テスト。
- `packages/shared` / `packages/server` / `assets/data`: ゲームルールとゲームデータの変更対象外。
