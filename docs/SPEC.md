# すごろくバトル（仮称：BEEF HUNTER）仕様書 v2.0（拡張版）

原作「牛すじハンター」（たんしおレモン, Flash, Ver0.09）のルール・数値を再現する、オンライン対戦すごろくRPGのAndroidアプリ。
数値・ロジックは原作SWFの逆コンパイル結果（ActionScript3）から取得した確定値である（推測値なし）。
名称・キャラクター画像・BGM/SE・UI画像はすべてオリジナルに差し替える（原作素材は同梱しない）。

---

## 0. 調査結果サマリ

| 項目 | 結果 |
|---|---|
| 公式配布物 | `https://tansio.net/game/net/sug/sug01.swf`（AS3, 640×480, 24fps）、マップ `map/map000.mgm`（標準）`map/map001.mgm`（短編） |
| 通信 | `_io_.cgi` へのHTTPポーリング（CGI_INTERVAL 288ms）。コマンドを積み上げ各クライアントが同じ乱数で同じ結果を再生する方式 |
| エミュレータ検証 | Ruffle 0.7.1でSWFの読込・起動ロゴ表示までは成功。以降はサイトロック（実行URLが `http://www.tansio.net/game/net/sug/sug01.swf` と完全一致する必要がある。現サイトはhttpsのため不一致）で停止し、ゲーム本編は動作しない |
| 結論 | 原作SWFのアプリ化流用は不可。ロジックは全数値取得済みのため、新規実装でほぼ完全再現が可能 |

## 1. 技術構成

| 層 | 採用 | 理由 |
|---|---|---|
| クライアント | TypeScript + Phaser 3 + Vite | 2Dタイル・スプライト・アニメに最適 |
| Android化 | Capacitor 6 | Web資産をそのままAPK化 |
| サーバ | Node.js 20 + Colyseus 0.15（サーバ権威型） | ルーム・状態同期・再接続が標準装備 |
| サーバ設置 | Render（無料枠）またはFly.io | 無料で常時WebSocket可能 |
| ビルド | GitHub Actions → `app-release.apk`（Artifacts と Releases に出力） | |
| テスト | Vitest（ロジック単体）、Playwright（Web版E2E） | |

## 2. ゲーム全体ルール

- 人数：1〜4人。空き枠はCPUで補充できる（ホストが枠ごとに「CPU追加／空き」を選択）。1人＋CPU3人、2人のみ等すべて可。
- 勝利条件：ラスボス（`lastboss` マス）を倒したプレイヤーが優勝。結果画面「優勝者は ○○ さんです！」。
- ターン順：入室順に固定で循環。死亡中・行動停止中のプレイヤーは飛ばす。
- 1ターンの選択肢：「移動（さいころ）」「アイテム（フィールド用）」。アイテムは使用すると基本的にそのターンは終了。
- マップ選択：標準（妨害アイテム少なめ）／短編（?ボックス多め）／長編（本作オリジナル、§15.1）。

### 2.1 制限時間（オンライン時）

| 定数 | 値 | 内容 |
|---|---|---|
| CON_LIMIT_TIME | 60秒 | 各判断の制限時間 |
| DRAW_LIMIT_TIME | 30秒 | 経過後に残り秒数を表示 |
| CON_ERROR_COUNT | 3回 | 連続タイムアウトで離脱扱い |

タイムアウト時の既定動作：移動はスキップ、Yes/Noは「いいえ」、ショップは「買わない」、靴は「いらない」、?ボックスはキャンセル、戦闘はそのターンを終了。
3回連続タイムアウトしたプレイヤーは本作ではCPUに置き換える（原作は除外）。

## 4. マップ

`assets/data/mapNNN.json`（原作データから抽出）：

```json
{ "name":"standard", "width":64, "height":54, "tileSize":40,
  "terrain":[...],                     // width*height。0=なし、1〜36=地形タイル番号
  "objects":[{"x":..,"y":..,"type":"shop","dir":"left"}, ...],
  "path":[{"x":..,"y":..,"c":"up"}, ...] }
```

### 4.1 path（進行制御マス）

| c | 内容 |
|---|---|
| start | スタート |
| up / right / down / left | このマスに入ったらその向きへ進む（一本道を矢印でつないだ構造） |
| branch | 分岐。「楽な道（右）」か「険しい道（左）」を選ぶ（CPUは50%） |
| boss1 / boss2 | 中ボスの手前。ここを通過・停止する時点で前方の中ボスと強制戦闘 |
| lastboss | ラスボスの手前。通過・停止で強制戦闘。勝てば優勝 |

- 制御マスは移動途中の通過でも発動する（1歩以上進んだ後のみ）。戦闘後、残り歩数は消滅する。
- 中ボスは倒されるまで道をふさぐ。誰かが倒すと消滅し、以後は全員通過可能。
- ボスのHPは全プレイヤー共通で、受けたダメージは持ち越される（他人が削った分も有効）。

### 4.2 objects（マス目イベント）

NPC・敵は道の隣にいて、`dir` の向きの道マスに**止まった時だけ**発動する（通過では発動しない）。道上アイテム（がびょう・お金）はそのマス自体が対象。

| type | 発動 | 内容 | 消滅 |
|---|---|---|---|
| priest（神父） | 停止 | 現在地を復活地点に保存 | しない |
| inn（宿屋） | 停止 | 5Gで全回復（HP・MP）。CPUはHPかMPが半分未満なら泊まる | しない |
| shop（商人） | 停止 | 品揃えA/Bのどちらか（マス座標と乱数種で決定）から1つ購入 | しない |
| shoes（靴仙人） | 停止 | 運動靴か安全靴を1つもらう（いらないも可）。所持枠の空きか靴所持が必要 | しない |
| treasure（宝箱） | 停止 | 開ける/開けない（CPUは90%で開ける）。§6.2 | 取得または爆発で消滅。持ちきれない時は残る |
| qbox（?ボックス） | 停止 | ひよこ・吸収玉・ノロイから1つ選んでもらう（キャンセル可。CPUはランダム） | しない |
| tack（がびょう） | 停止 | 1ダイスのダメージ | 発動で消滅 |
| tack_big（凄いがびょう） | 停止 | 2ダイスのダメージ | 発動で消滅 |
| gold_small（お金） | 停止 | 1ダイス分のG獲得 | 発動で消滅 |
| gold_large（お金袋） | 停止 | 3ダイス合計のG獲得 | 発動で消滅 |
| enemy_* | 停止 | 戦闘（§5） | 撃破で消滅 |
| decor | — | 飾り（何もしない） | — |

- 安全靴所持時、がびょう・凄いがびょうはダメージ無効でそのまま消滅する。
- 「消滅」は全プレイヤー共通で、マップから消える。

## 5. 戦闘

| 敵（仮名） | HP | 攻撃ダイス | 撃破報酬G | ドロップ |
|---|---|---|---|---|
| スライム | 4 | 1 | 1ダイス | さいころ |
| カニ | 7 | 1 | 2ダイス | アミュレット |
| 植物 | 11 | 1 | 3ダイス | ぱるぷん玉 |
| 中ボス・獣 | 20 | 2 | 3ダイス | 勇者の剣 |
| 中ボス・悪魔 | 30 | 2 | 3ダイス | 勇者の盾 |
| ラスボス・牛魔王 | 40 | 2 | 3ダイス | なし（勝利で優勝） |

- 先攻はプレイヤー、以降は交互。逃走はできない。
- プレイヤーのコマンド：「たたかう」「アイテム（戦闘用）」。
- 通常攻撃のダメージ：ダイス（1個、剣玉所持で2個）の合計＋武器攻撃力−相手の防御力（下限0）。
- 敵の攻撃：攻撃ダイスの合計−プレイヤーの盾防御力（下限0）。敵の防御力は0。
- 勝利時：報酬ダイスのG獲得。所持枠が空いていればドロップを入手（満杯なら入手できない）。
- 敗北（HP0）時は§7の死亡処理を行い、ターン終了。敵のHPは減ったまま残る。

## 7. 死亡と復活

- HP0になったとき、エリクサーを持っていれば自動消費し、その場でHP全回復して続行する。
- 持っていなければ復活地点（初期値はスタート。神父に話しかけるかアミュレット使用で更新）へ戻り、HP・MPは全回復する。歩数（順位計算用）は復活地点時点の値に戻る。所持金・アイテムは失わない。

---

## 8. 乱数と同期

- サーバが全乱数を生成し、ダイス結果を確定させてから配信する（クライアントは演出のみ）。
- 原作はマス座標から派生する疑似乱数でショップ品揃え・宝箱・報酬ダイスを決めていた。本作ではゲームごとのシード付きPRNG（mulberry32）を使い、`rng(seed, x, y, counter)` で同じ性質を再現する。

## 9. CPU思考（原作準拠）

移動前に以下の順で判定する。

1. HPが半分以下なら75%の確率で、恩恵（MP4以上）→ りんごの順で回復する（戦闘中も同じ判定）。
2. 呪い状態で恩恵が使えるなら使う。
3. 自分の歩数が全体平均−10未満なら20%でぱるぷん玉 → ひよこを使う。
4. 5%で幸運（MP5以上）を使う。
5. 復活地点から25歩以上進んでいれば20%でアミュレットを使う。
6. 10%でノロイ → 吸収玉を使う。
7. それ以外はさいころを振る。

イベント時：宝箱は90%で開ける。宿屋はHPかMPが半分未満なら泊まる。分岐は50%。靴・?ボックスはランダム。ショップは20%で何も買わず、それ以外は高い順に「買える・所持していない・上位互換でない」物を80%の確率で購入する。

## 10. オンライン仕様

### 10.1 画面遷移

タイトル → 名前入力（6文字まで）→ ロビー（ルームコード作成／コード入室／ランダムマッチ）→ ルーム（キャラ選択・マップ選択・CPU枠設定・チャット）→ フィールド ⇄ 戦闘 → 結果

### 10.2 ルーム

- 定員は4人。ゲーム中のルームには入れない。
- 開始条件：4人揃う、または全員が「開始」を押す。人数不足の枠はCPU補充も選べる。
- チャットは文字色4色を選べる（原作どおり）。システムメッセージもチャット欄に流す。
- 切断した場合は60秒以内なら同じ席へ再接続できる（Colyseus allowReconnection）。間に合わなければCPUが引き継ぐ。

### 10.3 メッセージ（client → server）

```
roll                    // さいころを振る
useItem {slot}          // アイテム使用
select {index}          // Yes/No・分岐・ショップ・靴・?ボックスの選択
battleAttack
chat {text, color}
ready / setCpu {seat, on} / setChar {id} / setMap {id}
```

server → client は状態（`schema`）の差分と、演出用の `event {type, payload}`（dice, damage, getItem, getGold, explode, swap など）を送る。

### 15.3 ぱるぷん玉<極>

**取得判定**
- ぱるぷん玉を新たに入手した瞬間（宝箱・ショップ・敵ドロップ・大豊作など）に、サーバ乱数で20%（ハウスルールで変更可）の確率で `kiwami=true` を付ける。
- 奪取（吸収玉・大強奪）で移った場合は、元の極状態をそのまま引き継ぐ（再判定しない）。
- 処理順：大強奪は「対象ごとに奪う個数を決定 → 使用者の次のプレイヤーから順にランダムに抜き取り、空き枠へ入れる → 入りきらない分は破棄 → 使用者に99ダメージ」の順で行う。

**秘匿**
- 名前・アイコン・説明文・所持品画面は通常のぱるぷん玉と完全に同じにする。
- `kiwami` はサーバ専用の状態に持ち、Colyseusスキーマへ同期しない（クライアントへは一切送らない）。所有者本人にも、使用するまで分からない。
- CPUの思考も極かどうかを参照しない（通常のぱるぷん玉として判断する）。

**使用時**
- 使用時に初めて判明する。演出は「ぱるぷん玉を使った！」の直後に画面が金色に反転し、「……ぱるぷん玉<極>だった！」と表示する。
- 1ダイスを振り、下表の効果を発動する。通常版より強力だが、出目によっては使用者にも代償がある。

| 出目 | 名称 | 効果 |
|---|---|---|
| 1 | 天罰 | 使用者以外の全員に99ダメージ（エリクサーで復活可） |
| 2 | 神の祝福 | 使用者の最大HP・最大MPを恒久的に+5し、全回復。呪いを解除 |
| 3 | 黄金の雨 | 使用者以外の全員から、それぞれの所持金の半分（切り捨て）を奪う |
| 4 | 大強奪 | 使用者以外の全員から、それぞれの所持アイテム数の半分（小数点以下切り上げ）をランダムに奪う。使用者の空き枠に入りきらなかった分は奪えず、そのまま捨てられる（元の持ち主にも戻らない）。奪った後、使用者自身に99ダメージ（エリクサーがあれば復活。奪ったアイテムは死亡しても保持する） |
| 5 | 大豊作・極 | 使用者の空き枠を、宝箱テーブルの上位（idx10〜15）からランダムに埋める |
| 6 | 時空逆転 | 使用者が1位でなければ、1位と位置・歩数を交換する。使用者が1位なら、自分のアイテムをランダムに1つ失い、その後ぱるぷん玉を2つ得る（それぞれ通常の入手として極判定を行う。空き枠が足りない分は得られない） |

- 通常版のぱるぷん玉と同じく、使用後はそのターンを終了する。
- 戦闘中は使用できない（フィールド専用）。

## 16. ゲームモード・ハウスルール

ルーム作成時に設定する。

| 設定 | 選択肢 | 既定 |
|---|---|---|
| マップ | 標準／短編／長編 | 標準 |
| ルール | クラシック（原作のみ）／拡張 | 拡張 |
| ターン上限 | なし／30／50／80ターン | なし |
| 上限到達時の勝者 | 歩数最多／所持金最多 | 歩数最多 |
| 初期所持金 | 20G／50G／100G | 20G |
| 極の出現率 | 0%／20%／50% | 20% |
| CPUの強さ | 弱い／普通（原作準拠）／強い | 普通 |
| 行動の制限時間 | 30／60／90秒 | 60秒 |

**CPU「強い」の変更点**
- 宿屋はHPが7割未満で泊まる。
- ショップは期待値の高い順に購入する（剣玉 > 鉄の剣 > 鉄の盾 > エリクサー）。
- 分岐は、HPが最大の6割以上なら険しい道を選ぶ。
- ひよこは1位との差が10歩以上あるときに優先して使う。

**CPU「弱い」の変更点**：アイテムを使う確率を半分にし、宝箱を開ける確率を70%にする。

## 17. オンライン機能の強化

| 機能 | 内容 |
|---|---|
| フレンドコード | 8桁コードで相互登録。フレンドのルームに直接参加できる |
